# Blake documentation entry point

Use the [documentation map](README.md) for the complete guide structure.

- [Quick start](quickstart.md): choose portable methods or the optional corpus stack.
- [Shared methods](shared-methods.md): source-bound matching, analysis and review APIs.
- [Applications](applications.md): portable corpus custody and independent papers.
- [User guide](user-guide.md): run and inspect the local corpus workflow.
- [API reference](api-reference.md): implemented interfaces and owning source.
- [Project status](PROJECT_STATUS.md) and [verification](verification.md): actual qualifications and next work.
- [Manuscript guide](manuscript/README.md): retained paper and native reproduction.

Plain `uv sync --locked` selects methods dependencies. Corpus commands require
the `full` extra; serving and complete test collection need their documented
additional extras. [Installation profiles](README.md#installation-profiles).
