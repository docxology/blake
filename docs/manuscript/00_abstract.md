# Abstract {#sec:abstract .unnumbered}

William Blake's works survive across editions, copy records, image archives, museum catalogues, transcriptions, and finding aids. Computational coverage is difficult to assess without explicit units, source authority, and evidence boundaries. We present *blake*, a {{PHASE_COUNT}}-phase pipeline that connects a {{TARGET_TOTAL}}-entry work-level target ledger with retained source records, local analysis, provenance, recoverability checks, and generated publication artifacts.

The saved offline run analyzes {{WORKS_PRESENT}} local source/copy records. Its {{TOTAL_IMAGES}} image associations reference {{UNIQUE_IMAGE_FILES}} distinct files. It represents {{TARGETS_REPRESENTED}} ledger targets ({{REPRESENTATION_PCT}}%) and fully satisfies the declared evidence profile for {{TARGETS_PRESENT}} targets ({{COVERAGE_PCT}}%). The text-bearing subset has {{WORKS_WITH_TEXT}} records and {{WORDS_TOTAL}} tokenizer-defined words. These exploratory text results include retained transcriptions with unverified authorship; they are not a Blake-authored language census. The top-level analysis ledger records {{ANALYSIS_WORKS_ANALYZED}}/{{ANALYSIS_WORKS_TOTAL}} records analyzed and {{ANALYSIS_ERROR_COUNT}} top-level errors. Nested sub-analysis limitations are counted separately.

Local recovery preserves {{RECOVERY_FILES}} inventoried files and {{RECOVERY_IMAGES}}/{{RECOVERY_IMAGE_REFERENCES}} discovered image identifiers, leaving {{RECOVERY_UNRESOLVED_IMAGES}} unresolved. Checksums and a corruption-detection restore drill establish recoverability of the captured inventory, not completeness of Blake's oeuvre. Quantitative prose, tables, and figures derive from saved artifacts. Public releases contain project-authored software, manuscript sources, aggregate evidence, and checksums; provider texts, XML, images, private indexes, backups, and source-image mosaics remain local. The contribution is an auditable corpus-governance and preservation method with explicit scholarly and distribution limits.
