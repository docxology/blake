# Supplement: Aggregate Image and Evidence Profiles {#sec:supp_visual_mosaics}

This public supplement reports aggregate inventory and provenance graphics. The local generator also produces `all_acquired_images_mosaic.png` and `work_area_image_mosaics.png` for private cache inspection. Those mosaics contain provider-supplied images and are excluded from the public manuscript, HTML, and release archives. Their generation does not grant redistribution rights. The public figures below contain project-authored aggregate marks rather than acquired source images [@drucker2020visualization; @kirschenbaum2008mechanisms].

![Compact target-ledger overview, intended for enlargement in the accompanying PNG. Each tile records the target's ledger status. Text availability (T) and image associations (I) describe only its first matched source/copy record; they do not aggregate all matching copies. Targets without a match show no text and zero image associations. The ledger unit differs from a source/copy record and from a physical image file.](../../output/figures/work_evidence_profile_grid.png){#fig:work_evidence_profile_grid}

![Archive image depth by local source record for the largest image carriers. Bars report resolved object candidates and locally available image associations in retained metadata. Reused physical files can contribute to multiple record-level bars; this is not an independent-image census.](../../output/figures/image_depth_by_work.png){#fig:image_depth_by_work}

![Archive image depth aggregated by target-ledger work area. Counts describe object candidates and local image associations attached to retained records. They do not measure completeness across museum collections or Blake's entire visual oeuvre.](../../output/figures/image_depth_by_area.png){#fig:image_depth_by_area}

![Source-authority tiers attached to local metadata records. Archive-primary identifies a source relationship, not independent verification that every extracted transcription is Blake-authored primary reading text. Reading-text authorship remains a separate classification.](../../output/figures/source_authority_tiers.png){#fig:source_authority_tiers}
