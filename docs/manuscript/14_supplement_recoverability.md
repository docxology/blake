# Supplement: Local Recovery and Integrity Evidence {#sec:supp_recoverability}

The captured inventory contains {{RECOVERY_FILES}} files totaling {{RECOVERY_BYTES}} bytes and is bound by manifest SHA-256 `{{RECOVERY_MANIFEST_SHA256}}`. Its source scope is the pinned Archive repository and retained Erdman API response, rather than every Blake holding. Source-inventory recovery is `{{RECOVERY_SOURCE_STATUS}}`; whole-oeuvre coverage is `{{RECOVERY_OEUVRE_STATUS}}`.

The extraction ledger contains {{RECOVERY_DOCUMENTS}} source/copy documents and {{RECOVERY_READING_RECORDS}} nonempty reading transcriptions. Of those, {{RECOVERY_PRIMARY_RECORDS}} carry primary-reading labels and {{RECOVERY_UNVERIFIED_RECORDS}} retain unverified authorship. The retained Erdman response has {{RECOVERY_PAGE_RECORDS}} page records, of which {{RECOVERY_NONEMPTY_PAGES}} are nonempty. The private projection contains {{RECOVERY_PROJECTION_RECORDS}} records across reading, editorial-page, and XML source planes. These planes have different meanings and are not pooled into a Blake-authored occurrence denominator.

Image recovery obtained {{RECOVERY_IMAGES}} of {{RECOVERY_IMAGE_REFERENCES}} discovered image identifiers ({{RECOVERY_IMAGE_PCT}}%). It leaves {{RECOVERY_UNRESOLVED_IMAGES}} unresolved identifiers. The nominal source resolution codes are {{RECOVERY_HIGH_RES_IMAGES}} files at {{RECOVERY_HIGH_RES_CODE}} and {{RECOVERY_LOW_RES_IMAGES}} at {{RECOVERY_LOW_RES_CODE}}; these codes describe requested variants, not independently measured scan resolution. The image-recovery status remains `{{RECOVERY_IMAGE_STATUS}}`.

The retained portable backup contains {{RECOVERY_BACKUP_BYTES}} bytes, with SHA-256 `{{RECOVERY_BACKUP_SHA256}}`. The prior offline restore drill verified {{RECOVERY_RESTORE_FILES}} restored files, then deliberately corrupted a copied transcription. Verification rejected that copy before repair restored the inventoried bytes. The drill receipt has SHA-256 `{{RECOVERY_RESTORE_DRILL_SHA256}}`. Current integrity verification rechecks the captured files and existing backup; it does not repeat or overwrite the historical restore experiment. This demonstrates recoverability of the captured inventory, not recovery of unknown or unavailable source material.

Raw transcriptions, TEI/XML, images, private indexes, backup archives, and restore copies remain ignored local materials. Public deposits contain project-authored code, manuscript sources, derived aggregate evidence, and checksums. Exact byte identity does not establish transcription accuracy, Blake authorship, scholarly completeness, or redistribution permission [@owens2018digitalpreservation; @candela_collections_data].
