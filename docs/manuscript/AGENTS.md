# Manuscript Authoring Contract (blake)

> This file is **excluded from `{{TOKEN}}` injection** (along with `README.md`, `SYNTAX.md`).
> It documents the contract; it is not rendered into the PDF.

## The no-hard-coded-variables invariant

Every quantitative value in the manuscript body (`NN_*.md`) is cited through a
`{{UPPERCASE_TOKEN}}` marker. The tokens are computed by
`manuscript_tools/variables.py` (`generate_variables`) reading the JSON artifacts
under `analysis_output/` (produced by the corpus pipeline). The render pipeline runs
`scripts/z_generate_manuscript_variables.py`, which writes
`output/data/manuscript_variables.json` and substitutes the tokens into
`output/manuscript/*.md` via `infrastructure.rendering.manuscript_injection`.

**Rules for authors (human or agent):**

1. Never hard-type a result number, count, percentage, or word count. Use a token.
2. The allowed tokens are exactly the keys in `output/data/manuscript_variables.json`.
   A `{{TOKEN}}` not in that set renders literally — a visible defect.
3. `config.yaml` `title`/`subtitle` are **not** substituted — keep all numbers out of them.
4. Figure captions follow the same rule: numbers come from tokens, not literals.
5. Prefer structural/guarantee framing over value-specific adjectives next to tokens
   (e.g. "the present corpus covers a small fraction of the ledger" not "is negative").

## Honesty contract

This manuscript reports a **target-aware, partial full-corpus acquisition run**, not a
completed Blake corpus. Coverage against the canonical target ledger is partial and must
be stated as such. No sentence may claim the system "analyzed Blake's complete works."
Prose asserts only analyses present in shipped `blake/` code and must distinguish
complete target evidence from partial or missing target evidence. Distribution prose must
also distinguish the MIT-licensed project code from source-provider texts, TEI files,
images, and local caches that are governed by provider terms or item-level rights.

## Regenerate everything

```bash
# from the blake project root
uv run blake corpus audit-sources --limit 16 --output-dir analysis_output --archive-scope archive-inventory
uv run blake corpus acquire-evidence --from-audit analysis_output/data/source_audit.json --dry-run
uv run blake corpus acquire-evidence --from-audit analysis_output/data/source_audit.json
uv run blake corpus run --skip-download --output-dir analysis_output --fixture-mode never --viz-profile core --format json --archive-scope archive-inventory --image-mode archive-all --image-dpi 300 --max-images-per-work none
uv run python scripts/generate_manuscript_figures.py
# from the template repo root, or with TEMPLATE_REPO_ROOT pointed at it
uv run python scripts/03_render_pdf.py --project working/blake                 # hydrate + PDF
uv run python scripts/04_validate_output.py --project working/blake            # validate PDF/web outputs
```
