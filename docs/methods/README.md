Use [shared methods](../shared-methods.md) for the public API and
[application integration](../applications.md) for source custody and ownership.

| Note | Scope |
|---|---|

Applications supply the domain vocabulary, eligibility policy and contextual
decisions. A shared calculation or selected workload does not adjudicate a
literary mention. [Verification](../verification.md) records installed SDK and
optional-stack checks separately from manuscript and scientific acceptance.
