# Visualization Publication Brief

This inventory records the story job, source, encoding, caveat, fallback, QA check, and statistical mini-brief for registered local figures. `scripts/generate_manuscript_figures.py --public-only` selects the aggregate figures used by the public paper and excludes source-image mosaics, stale source-health displays, and chronology. The default local mode retains the full registry. Filenames and labels remain stable; `output/figures/figure_registry.json` records its explicit `public` or `local` scope at schema `1.5`.

The current visual contract is PDF-first, accessible, and static-output safe: figure text must be readable after manuscript scaling, high-density figures must carry direct labels or embedded keys, and crowded notes must move into compact subtitles or in-figure caveats rather than overloaded titles. Web and mobile output should preserve the same reading order without relying on hover or external legends.

All figures and the corpus workbench use a shared restrained palette: neutral warm background, dark ink text, muted grid lines, and colorblind-aware semantic accents for present/partial/missing/unverified/duplicate states. Color is never the only channel for status; labels, counts, percentages, chips, or table text must carry the same information.

Every registry figure must include these statistical fields:

- `statistical_question`: the descriptive question the visual answers.
- `data_shape`: the artifact grain, such as one target row, one work row, or one image-depth row.
- `statistical_method`: the descriptive method used; current figures are run/census diagnostics, not inferential estimates.
- `missingness_or_scope`: the denominator, exclusion, or rights/scope caveat needed to prevent overclaiming.
- `statistical_check`: the figure-specific check that keeps denominators, labels, or scope visible.
- `statistics`: a JSON-serializable object regenerated from `analysis_output/`, not hand-authored prose.

The figure families use the following statistic patterns:

- Coverage/category/modality/source figures report target/work denominators, status counts, percentages, unresolved shares, and run/source caveats.
- Text figures report text-work `n`, total and share-of-total words, document frequency, top-term share, length-band caveats, and median/IQR summaries where length sensitivity matters.
- PCA and text-image scatter figures report feature count, work count, variance, top-axis terms, zero-image mass, outliers, and descriptive local-run correlations only.
- Image-depth/profile/mosaic/authority figures report resolved-vs-downloaded ratios, completion status counts, missing-path exclusions, rights-gate notes, category totals, and authority-tier percentages.

Figure QA now also checks that:

- Titles state the claim or question, while subtitles carry run status, denominator, or caveat detail.
- Labels remain legible in the rendered PDF, not just in full-resolution PNGs.
- Acquisition reuse and generated analysis states are visible in the pipeline DAG without implying skipped analysis.
- Scatterplot labels are limited to the highest-value outliers and use callouts that do not hide dense point clouds.
- Mosaic/profile figures keep overview density, but headings and profile tiles use larger fonts where the reader is expected to inspect labels.
- Web workbench chips and in-cell bars match the static figure palette and preserve readable contrast in grayscale or print-like conditions.
