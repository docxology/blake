# examples/ Directory

Example scripts demonstrating Blake package usage.

## Scripts

| Script | Purpose |
|--------|---------|
| `basic_usage.py` | Basic API usage |
| `advanced_analysis.py` | Analysis demonstrations |
| `download_all.py` | Download all works |
| `comprehensive_acquisition_demo.py` | Multi-source download demo |
| `blake_interactive.py` | Interactive terminal |
| `interactive_demo.py` | Interactive demo |
| `project_b_demo.py` | Visualization demo |

## Running Examples

```bash
# Basic usage
uv run python examples/basic_usage.py

# Interactive mode
uv run python examples/blake_interactive.py
```
