# Blake manuscript

Publication-track manuscript for the Blake Corpus Analysis Platform
(see repo root `README.md`): a source-governed corpus of William Blake texts
and images with coverage, text-analysis, and legal-distribution findings.

## Files

| File | Role |
|---|---|
| `config.yaml` | Paper metadata (paper, authors, publication, keywords, metadata, render blocks) |
| `00_abstract.md` … `09_conclusion.md` | Core sections in reading order |
| `06a_legal_distribution.md` | Public-domain / legal-distribution analysis |
| `10_supplement_evidence_gaps.md` … `13_supplement_rights_matrix.md` | Supplements |
| `99_references.md` | References |
| `references.bib` | Bibliography |
| `preamble.md` | Render preamble |
| `legal_claim_ledger.yaml` | Claim ledger backing the legal/supplement sections |
| `assets/` | Manuscript figures/assets |
| `AGENTS.md`, `SYNTAX.md` | Authoring contract and token syntax (excluded from token injection) |

## Token injection

Every quantitative value in the body is cited through `{{UPPERCASE_TOKEN}}`
substitution — see `AGENTS.md` ("no-hard-coded-variables invariant") and
`SYNTAX.md`. Unresolved tokens in these source files on disk are expected;
they are replaced at render time from `../output/data/manuscript_variables.json`
(generated by `../manuscript_tools/variables.py` via
`../scripts/z_generate_manuscript_variables.py`). Do not hand-type numbers.
